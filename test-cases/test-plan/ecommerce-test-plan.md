# E-commerce Test Plan

## Objective
Validate the main functionality of an e-commerce application and identify critical defects before release.

## Scope

### In Scope
- Login
- Product browsing
- Shopping cart
- Checkout
- Logout

### Out of Scope
- Payment gateway integration
- Performance testing
- Security penetration testing

## Test Types
- Functional Testing
- Negative Testing
- Regression Testing
- Exploratory Testing

## Test Environment
- Web application
- Google Chrome
- Windows 11

## Entry Criteria
- Application is available for testing
- Test environment is stable
- Requirements are available

## Exit Criteria
- All critical test cases executed
- No open Critical defects
- Major functionality works as expected

## Deliverables
- Test Cases
- Test Execution Results
- Bug Reports
- Test Summary
